# To-do list

A responsive to-do app built with vanilla HTML, CSS, and JavaScript.

## Run it

Open `index.html` in a browser. No dependencies or build step are needed.

## Features

- Add tasks with a Personal or Work category, complete them, and delete them
- Filter tasks by all, active, or completed
- Clear completed tasks
- Save tasks in browser local storage
- Responsive layout with keyboard-accessible controls
